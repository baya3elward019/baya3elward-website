# موقعي الشخصي — دليل الاستخدام

موقع بورتفوليو سايبر سكيوريتي: مقالات و Write-ups، مشاريع، شهادات، معرض صور، وصفحة تعريف بيك.
الموقع **ستاتيك** على GitHub Pages (مجاني، سريع، ومفيهوش سيرفر حد يخترقه)، وبتضيف المحتوى من **واجهة في المتصفح** اسمها Pages CMS من غير ما تلمس كود.

- ثيمين: داكن (أزرق نيون) وفاتح، وبيتبدلوا بزرار الشمس/القمر فوق بأنيميشن دائرية.
- أنيميشن: شاشة إقلاع أول ما حد يفتح الموقع، شبكة متحركة في الخلفية بتتفاعل مع الماوس، اسمك بيتفك تشفيره، typing للأدوار، كروت بتميل مع الماوس، ظهور تدريجي مع الـ scroll، وانتقال ناعم بين الصفحات.
- لو الزائر مفعّل "تقليل الحركة" في جهازه، الأنيميشن بتقف تلقائي.

---

## 1) أول مرة: رفع الموقع على GitHub

> لو أنا (Claude) رفعت الملفات على الريبو بنفسي، اقفز على الخطوة 2.

1. فك ضغط ملف `baya3elward-website.zip` على جهازك.
2. افتح الريبو على GitHub ← **Add file** ← **Upload files**.
3. اسحب **كل اللي جوه الفولدر** (مش الفولدر نفسه) وافلته في الصفحة، ثم **Commit changes**.
4. **مهم:** في ملفين اسمهم بيبدأ بنقطة، وبعض الأجهزة بتخفيهم فمش هيترفعوا بالسحب. اتأكد إنهم موجودين في الريبو:
   - `.pages.yml`
   - `.github/workflows/deploy.yml`

   لو مش موجودين: **Add file ← Create new file**، اكتب الاسم بالظبط (مع النقطة والمسار)، وانسخ محتواه من الملف اللي عندك، وبعدين **Commit**.

## 2) تشغيل GitHub Pages (مرة واحدة)

1. في الريبو: **Settings ← Pages**.
2. تحت **Build and deployment ← Source** اختار **GitHub Actions**.
3. روح تبويب **Actions**، هتلاقي "Deploy to GitHub Pages" شغال. لو مش شغال، افتحه واضغط **Run workflow**.
4. بعد دقيقة تقريباً الموقع يبقى على:
   **https://baya3elward019.github.io/baya3elward-website/**

الكود بيعرف اسم الريبو لوحده ويظبط الروابط، فمش محتاج تعدل أي حاجة.

## 3) ربط Pages CMS (لوحة التحكم) — مرة واحدة

1. افتح **https://app.pagescms.org** واضغط **Sign in with GitHub**.
2. هيطلب منك تثبت تطبيق Pages CMS على حسابك. اختار **Only select repositories** وحدد `baya3elward-website`.
3. اختار الريبو من القائمة، هتلاقي في الجنب: **Profile & links**، **Write-ups & articles**، **Projects**، **Certificates**، **Gallery**، و **Media**.

احفظ الرابط ده في الـ bookmarks، ده الداشبورد بتاعك.

> كل مرة تدوس **Save** في Pages CMS، التعديل بيتحفظ في الريبو، والموقع بيتحدث لوحده خلال دقيقة أو اتنين.

## 4) إضافة وتعديل المحتوى

### تعديل بياناتك (الاسم، الصورة، النبذة، السوشيال)
**Profile & links** ← عدّل ← **Save**.
- **Roles**: الجمل اللي بتتكتب وتتمسح تحت اسمك. حط 2 أو أكتر.
- **About me**: سيب سطر فاضي بين كل فقرة والتانية.
- **Skill groups**: كل مجموعة ليها اسم (مثلاً Offensive) وتحتها المهارات.
- **Social links**: اختار المنصة وحط الرابط. الواتساب يكون كده: `https://wa.me/218XXXXXXXXX` (رقمك بكود الدولة من غير + أو أصفار في الأول).
- **Profile photo**: ارفع صورتك. الأفضل تكون مربعة.

### إضافة مقال أو Write-up
**Write-ups & articles** ← **Add an entry**:
- **Title** و **Short description** (بتظهر في الكارت).
- **Type**: Write-up / Article / Experiment / News.
- **Platform** و **Difficulty**: اختياري، للـ write-ups.
- **Tags**: كلمات للفلترة، زي `web`, `xss`.
- **Cover image**: صورة الغلاف (اختياري).
- **Content**: المحتوى نفسه. تقدر تحط عناوين وصور ولينكات وقوائم من شريط الأدوات.
- **Save**.

**الأكواد (code blocks):** اضغط زرار **Source** فوق المحرر، واكتب الكود بين ثلاث علامات ``` واسم اللغة:

````
```bash
nmap -sC -sV 10.10.10.10
```
````

الموقع هيعرضه في شباك terminal فيه زرار copy. اللغات المشهورة: `bash`, `python`, `js`, `html`, `sql`, `powershell`.

**العناوين** (Heading 2 و Heading 3) بتتحول لفهرس "On this page" على جنب المقال تلقائياً.

### إضافة شهادة
**Certificates** ← **Add an entry** ← الاسم، الجهة، التاريخ، **صورة الشهادة**، ولينك التحقق لو موجود ← **Save**.
لما حد يضغط على الشهادة بتفتح كبيرة في popup.

### إضافة مشروع
**Projects** ← **Add an entry**:
- **Cover image** + **Screenshots** (تقدر ترفع كذا صورة).
- **Type**: نوع المشروع (Game / Web app / Website / Tool). ده اللي بيحدد كلمة الزرار: اللعبة بيطلعلها **Play now**، والتطبيق **Open app**.
- **Live link**: رابط اللعبة أو الموقع نفسه (مثلاً `https://baya3elward019.github.io/skruu/`). لما تحطه بيظهر زرار على كارت المشروع يفتحه مباشرة، وزرار تشغيل فوق الصورة لما الماوس ييجي عليها.
- **GitHub link**: رابط الريبو، بيظهر كزرار **Code**.
- **Featured**: علّم عليها عشان المشروع يظهر أول واحد في الصفحة الرئيسية.
- **Details**: لو كتبت فيها حاجة، المشروع بيبقى ليه صفحة خاصة. لو سبتها فاضية، الكارت بيفتح رابط GitHub/الديمو مباشرة.

### إضافة صور للمعرض
**Gallery** ← **Add an entry** ← عنوان + صورة + تاريخ + وصف ← **Save**.

### تعديل أو حذف أي حاجة
افتح القسم، اختار العنصر، عدّل واحفظ. للحذف: هتلاقي خيار **Delete** في قائمة العنصر (أو جوه صفحة تعديله).

### Draft (مسودة)
علّم على **Draft** لو عايز تحفظ حاجة من غير ما تظهر على الموقع لسه.

## 5) المحتوى التجريبي

الموقع جاي فيه أمثلة عشان تشوف الشكل: 3 مقالات، مشاريعك المرفوعة على GitHub بروابطها الحقيقية (السطو الصامت، سكرو، القطار الأخير، Sigil Duel، Study Lab، مصروفي) + 3 مشاريع بوصف مبدئي (BRMS ومشروع الشبكات وyt_download)، 4 شهادات **وهمية** مكتوب عليها SAMPLE، و4 صور تجريبية.
**امسح الشهادات والصور التجريبية** وحط الحقيقي، وعدّل المشاريع والمقالات أو امسحها.

## 6) نصايح

- صغّر الصور قبل الرفع (أقل من 1MB تقريباً)، عشان الموقع يفضل سريع. موقع زي squoosh.app بيعمل كده ببلاش.
- في الـ write-ups: انشر حلول الماشينات والغرف **الـ retired بس**. منصات زي Hack The Box و TryHackMe بتمنع نشر حلول المحتوى النشط.
- ما تحطش في المقالات IPs أو باسوردات أو بيانات حقيقية من شغل أو عملاء.

## 7) لو حاجة مش شغالة

| المشكلة | الحل |
|---|---|
| الموقع مش ظاهر بعد الرفع | Settings ← Pages ← Source لازم تكون **GitHub Actions**. |
| تعديل من Pages CMS مش ظاهر | استنى دقيقتين واعمل refresh. شوف تبويب **Actions**: لو فيه ❌ افتحه وشوف الخطأ. |
| Actions فيها ❌ بعد ما ضفت حاجة | غالباً حقل مطلوب فاضي (العنوان أو التاريخ). افتح العنصر في Pages CMS وكمّله. |
| Pages CMS مش شايف الأقسام | اتأكد إن ملف `.pages.yml` موجود في أول الريبو. |
| صورة مش ظاهرة | ارفعها من Pages CMS نفسه، مش من برا. |

## 8) حاجات متقدمة (اختيارية)

**تغيير الألوان:** الملف `src/styles/global.css`، أول جزء فيه الألوان لكل ثيم (`--accent` هو اللون النيون الأساسي). عدّلها من GitHub بزرار القلم ✏️.

**دومين خاص (مثلاً baya3.dev):** بعد ما تربطه من Settings ← Pages ← Custom domain، افتح `.github/workflows/deploy.yml` وحط:
```yaml
SITE_URL: "https://baya3.dev"
SITE_BASE: "/"
```

**تشغيله على جهازك (للمطورين):** `npm install` ثم `npm run dev`.

### هيكل المشروع

```
.pages.yml                  ← إعدادات لوحة التحكم (Pages CMS)
.github/workflows/deploy.yml← البناء والنشر التلقائي
public/images/uploads/      ← الصور اللي بترفعها من الـ CMS
src/
  data/profile.json         ← بياناتك (بتتعدل من Profile & links)
  content/writeups/         ← المقالات (ملف Markdown لكل مقال)
  content/projects/         ← المشاريع
  content/certificates/     ← الشهادات
  content/gallery/          ← المعرض
  pages/                    ← صفحات الموقع
  components/               ← أجزاء الواجهة (الكروت، النافبار…)
  styles/                   ← التصميم والألوان
  scripts/main.ts           ← الأنيميشن والتفاعل
```

مبني بـ [Astro](https://astro.build) ومستضاف على GitHub Pages، والمحتوى بيتدار من [Pages CMS](https://pagescms.org).
